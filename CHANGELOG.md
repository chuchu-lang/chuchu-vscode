# Changelog

## 0.1.1

Apply the Chuchu logo to the extension and documentation, and configure the sibling local Cheeku build for extension development. The extension icon is now the 256×256 PNG mark with a transparent background.

## 0.1.0

Initial Chuchu language support: syntax highlighting, snippets, scope-aware completion and navigation, hover documentation, signature help, outline, folding, lexical diagnostics, and Cheeku build commands.
